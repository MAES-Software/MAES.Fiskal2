# Pravila sigurnosti

## Podržane verzije

Sljedeće verzije projekta trenutno primaju sigurnosne nadogradnje i ispravke:

| Verzija | Podržana |
| -------- | --------- |
| 0.2.x    | ✅ |
| 0.1.x    | ❌ |

## Prijava sigurnosnih ranjivosti

Ako pronađete sigurnosni problem ili potencijalnu ranjivost, molimo vas da je prijavite putem e-mail adrese:

info@maesdbk.hr

Prilikom prijave pokušajte uključiti što više informacija:

- opis problema
- korake za reprodukciju
- potencijalni utjecaj ranjivosti
- primjere zahtjeva / odgovora ako postoje
- verziju sustava ili biblioteke na kojoj je problem pronađen

Molimo da sigurnosne probleme ne objavljujete javno prije nego što problem bude analiziran i ispravljen.

Nakon zaprimanja prijave:
- potvrdit ćemo primitak prijave u razumnom roku
- analizirati prijavljeni problem
- obavijestiti vas o statusu i eventualnom rješenju

Zahvaljujemo na odgovornom prijavljivanju sigurnosnih problema i pomoći u poboljšanju sigurnosti projekta.
